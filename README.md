## 简介

液态玻璃·灵动工具箱，以通透液态玻璃视觉为核心的多功能工具集合，覆盖 Android、Windows Desktop、iOS 三端。

## 下载

| 平台 | 安装包 | 说明 |
|------|--------|------|
| Android | [LiquidGlass-v2.9.2.apk](https://github.com/jiangtengqiao/liquid-glass/releases/download/v2.9.2/LiquidGlass-v2.9.2.apk) | 直接安装 |
| Windows | 见 Release 页 | 需自行打包或下载预编译版 |
| iOS | 源码编译 | 需 Mac + Xcode |

## 核心特性

- **液态玻璃视觉** — 真实光学折射效果，通透质感
- **大道至简主题** — 深色 / 浅色 / 系统自动跟随
- **Beta 先锋体验** — 问卷申请 + 先锋体验码，抢先内测
- **公告与日志系统** — 顶部公告推送 + 崩溃日志自动上报
- **全平台同步** — Android / Windows / iOS 三端推进

## 工具模块

时钟天气、科学计算器、音乐播放器（网易云）、待办清单、指南针、手电筒、倒计时、壁纸库、画板、音频白噪音等。

## 系统要求

- **Android**：8.0（API 26）及以上
- **Windows**：10/11，需 JDK 17 运行环境
- **iOS**：15.0+
