## 一、网易云扫码授权完就过期死循环 — 根因修复

### 根因
1. `weapiPost` 手动设置 `Cookie` header，但 OkHttp 的 `cookieJar`（BridgeInterceptor）会覆盖手动设置的 Cookie header → 手动 Cookie 无效且可能与 cookieJar 冲突
2. `fetchAccount` 失败时（接口限流/网络抖动）直接返回 null，不检查 MUSIC_U cookie 是否已落库 → 登录态丢失 → UI 显示错误
3. `pollQrStatus` 网络失败直接返回 ERROR，UI 显示"重新生成二维码"（用户误以为是"过期"）

### 修复
1. **weapiPost 移除手动 Cookie header**：Cookie 完全由 cookieJar 自动管理（OkHttp BridgeInterceptor 调 loadForRequest/saveFromRequest）
2. **fetchAccount 兜底**：接口失败时检查 `hasLoginCookie()`（MUSIC_U 是否已落库），有则存最小用户信息返回成功
3. **pollQrStatus ERROR 重试**：网络失败重试 2 次而非直接显示错误
4. **QrLoginView CONFIRMED 后等 fetchAccount**：成功才 onLoginSuccess，失败显示明确错误而非"过期"

## 二、资源包下载速度优化

### 问题
- buffer 8KB 太小，频繁系统调用 → 代理源限速下只有几十 KB/s
- 分块串行下载，未充分利用带宽

### 修复
1. **buffer 8KB → 256KB**：减少 read/write 系统调用次数
2. **4 路并发分块下载**：用 FixedThreadPool(4) 同时下载多个分块，充分利用带宽
3. 分块下载完成后按序拼合 + 字节数校验（杜绝代理截断）
