# v2.4.1 变更详解

> 发布日期：2026-07-30
> versionCode: 15 / versionName: 2.4.1
> 主题：音乐播放器核心 Bug 修复

v2.4.0 上线后用户反馈「网易云二维码一辈子加载不出来」「检测是否安装一坨」。本次定位并修复了这两个核心 Bug 及若干连带问题。

---

## 一、网易云扫码二维码加载不出来 — 根因修复

### 根因

`NetEaseApiClient` 使用 `lateinit var appContext`，初始化放在 `MusicScreen` 的 `LaunchedEffect(Unit)` 里：

```kotlin
// MusicScreen.kt (v2.4.0)
LaunchedEffect(Unit) {
    NetEaseApiClient.init(context)      // 异步，且与下面竞态
    MusicControllerManager.init(context)
}
```

而 `QrLoginView` 也在自己的 `LaunchedEffect(Unit)` 里调 `createQrKey()`：

```kotlin
// QrLoginView (v2.4.0)
LaunchedEffect(Unit) {
    generating = true
    unikey = NetEaseAuth.createQrKey()  // 内部 weapiPost 访问 appContext
    generating = false
}
```

两个 `LaunchedEffect(Unit)` 并发执行。若 `createQrKey` 先跑到 `weapiPost`，此时 `appContext` 尚未初始化 → 抛 `UninitializedPropertyAccessException` → 被 `catch (_: Exception) { null }` 吞掉 → `unikey = null` → `generating = false` → UI 走 else 分支显示「二维码已过期」。

**二维码永远出不来。**

### 修复

1. **NetEaseApiClient 的 `appContext` 改为 nullable**：
   ```kotlin
   @Volatile
   private var appContext: Context? = null
   ```

2. **新增 `ensureContext()` 自愈兜底**：
   ```kotlin
   private fun ensureContext(): Context {
       appContext?.let { return it }
       ContextProvider.appContext?.let { appContext = it; return it }
       throw IllegalStateException("...")
   }
   ```
   即便 `init` 晚于首请求，也能从全局 `ContextProvider` 拿到 context，不再崩。

3. **新增 `ContextProvider` 全局上下文持有者**：
   ```kotlin
   object ContextProvider {
       @Volatile var appContext: Context? = null
       fun init(context: Context) { ... }
   }
   ```

4. **MainActivity.onCreate 同步预初始化**：
   ```kotlin
   override fun onCreate(...) {
       super.onCreate(...)
       ContextProvider.init(this)          // 最早期
       NetEaseApiClient.init(this)         // 同步预初始化，消除竞态
       enableEdgeToEdge()
       ...
   }
   ```

5. **所有 `weapiPost` 内的 `appContext` 引用改为 `ensureContext()`**。

### 效果
二维码请求不再因竞态崩溃；即便首请求仍偶发失败，QrLoginView 也会自动重试。

## 二、QrLoginView 重写

### 问题
v2.4.0 的逻辑：`createQrKey` 返回 null 时 `generating=false` 但 `unikey=null`，UI 走 else 分支显示「二维码已过期」——但实际是网络/初始化失败，并非过期。用户看到「已过期」会困惑。

### 修复
重写状态机：
- `generating` 期间显示 loading + 「正在生成二维码…」
- `unikey != null` 且状态为 WAITING/SCANNED/CONFIRMED 时显示二维码
- `unikey == null && !generating` 时显示「生成失败，请检查网络」+ 重试按钮
- 否则才显示「二维码已过期」

生成 key 失败自动重试 3 次（间隔 1.5s），重试用完后才进入失败态。

## 三、退出登录后 UI 不刷新 — 修复

### 问题
v2.4.0 中 `NeteaseTab` 用 `if (!SessionStore.isLoggedIn(context))` 判断登录态。但 `SessionStore` 基于 SharedPreferences，**不是 Compose state**，登录/退出后不会触发重组 → UI 卡在登录页或登录后的界面。

顶部栏 VIP 徽章同理：`SessionStore.isLoggedIn(context) && SessionStore.isVip(context)` 在登录成功后不会自动刷新。

### 修复
1. **登录态提升为 Compose state**：
   ```kotlin
   var loggedIn by remember { mutableStateOf(SessionStore.isLoggedIn(context)) }
   ```

2. **`loginTick` 计数器触发父级重组**：
   ```kotlin
   // MusicScreen
   var loginTick by remember { mutableStateOf(0) }
   // 顶部栏
   val isLoggedIn = remember(loginTick) { SessionStore.isLoggedIn(context) }
   val isVip = remember(loginTick) { SessionStore.isVip(context) }
   // NeteaseTab
   NeteaseTab(onLoginChanged = { loginTick++ })
   ```

3. **QrLoginView 增加 `onLoginSuccess` 回调**，登录成功时通知父组件。

4. **退出登录同步清空播放队列**：
   ```kotlin
   TextButton(onClick = {
       NetEaseAuth.logout(context)
       MusicControllerManager.clearQueue()
       playlists = emptyList()
       loggedIn = false
       onLoginChanged()
   })
   ```

### 效果
- 扫码登录成功 → 顶部栏 VIP 徽章即时出现 → NeteaseTab 切换到歌单页
- 退出登录 → 徽章消失 → NeteaseTab 切回二维码页 → 播放队列清空

## 四、第三方音乐 App 检测是否安装错误 — 修复

### 根因
Android 11 (API 30) 起，默认包可见性限制：App 默认只能看到自己和少数系统 App，对其他第三方 App 调 `getPackageInfo` 会一律抛 `NameNotFoundException` → 永远返回 false → 永远显示「未安装」。

v2.4.0 的 manifest 没有 `<queries>` 声明。

### 修复
1. **AndroidManifest 新增 `<queries>`**：
   ```xml
   <queries>
       <package android:name="com.kugou.android" />
       <package android:name="com.luna.music" />
       <package android:name="com.tencent.qqmusic" />
       <package android:name="com.netease.cloudmusic" />
       <intent>
           <action android:name="android.intent.action.VIEW" />
           <data android:scheme="https" />
       </intent>
   </queries>
   ```

2. **双重检测**：
   ```kotlin
   val installed = remember(p.pkg) {
       try {
           context.packageManager.getPackageInfo(p.pkg, 0)
           context.packageManager.getLaunchIntentForPackage(p.pkg) != null
       } catch (_: Exception) { false }
   }
   ```

3. **跳转加固**：
   - 优先用 `getLaunchIntentForPackage`
   - launchIntent 为 null 时回退网页
   - `startActivity` try-catch 兜底，极端情况再回退网页

### 包名确认
- 酷狗音乐：`com.kugou.android` ✓
- 汽水音乐：`com.luna.music` ✓（经多个应用市场核实）
- QQ音乐：`com.tencent.qqmusic` ✓
