# v2.4.0 变更详解

> 发布日期：2026-07-30
> versionCode: 14 / versionName: 2.4.0
> 主题：音乐播放器 + 全功能复盘修缮 + 法律公告中心

本次更新是「灵工坊·智能工具箱」自 2.1.0 品牌升级以来最大的一次迭代。我们做了三件事：

1. **从零打造了一个完整的音乐播放器**，接入网易云音乐与本地音乐，并覆盖酷狗/汽水/QQ音乐跳转；
2. **对所有既有功能做了一次大规模复盘修缮**，修复了二维码乱码、汇率硬编码、壁纸预览不一致、待办退出即丢、日历无提醒等多个真实可用性问题；
3. **新增「法律与公告中心」**，收录 5 篇长文协议（隐私/服务/免责/第三方/儿童），让应用合规性达标。

## 一、全新音乐播放器

### 1.1 架构方向

经过多轮决策，最终架构定为：

- **网易云**：深度接入（扫码登录 + 搜索 + 歌单 + 播放URL + 歌词 + 会员状态），作为主力在线音源
- **本地音乐**：基于 MediaStore 扫描设备本地文件，作为离线音源
- **酷狗 / 汽水 / QQ音乐**：以「跳转入口」形式提供，不重复造轮子，尊重各平台生态
- **白噪音**：保持独立助眠功能定位，与新播放器解耦

### 1.2 网易云音乐接入

采用 **扫码登录** 方案（而非账密或游客），原因：

- 不收集用户密码，符合隐私最小化原则
- 可拿到 VIP 状态、私人歌单、每日推荐等需要登录态的能力
- 登录凭证仅保存在设备本地

实现细节：

- `NetEaseAuth.kt`：扫码 key 获取、二维码图片生成、轮询登录状态（800/801/802 三态处理）
- `NetEaseApi.kt`：搜索、歌单、播放URL、歌词（含 YRC 逐字歌词）、热搜词
- `NetEaseCrypto.kt`：weapi 加密（AES + RSA）
- `NetEaseApiClient.kt`：OkHttp 单例 + Cookie 管理

### 1.3 后台播放

使用 **Media3 (ExoPlayer + MediaSession)** 实现：

- 前台服务（Foreground Service）保活
- 通知栏控件（播放/暂停/上一首/下一首）
- 锁屏控件
- Android 13+ 通知权限运行时申请

`MusicControllerManager.kt` 封装了 MediaController 的连接、断开、命令发送。

### 1.4 歌词展示

采用 **逐字滚动 + 模糊渐变** 方案：

- 优先解析 YRC（逐字歌词），无 YRC 时回退 LRC（逐行）
- 当前演唱字高亮，前后字模糊渐变
- 歌词自动滚动跟随播放进度

### 1.5 播放队列管理

- 可视化队列页：展示当前播放列表
- 支持：移动顺序、删除单曲、清空队列、点击跳播
- 循环模式：单曲循环 / 列表循环 / 随机播放

### 1.6 搜索体验

- `SearchHistoryStore.kt`：搜索历史本地持久化（最近 20 条）
- 一键回溯历史搜索
- 网易云热搜词榜单展示

## 二、全功能复盘修缮

### 2.1 二维码/条形码重写

**问题**：
- 二维码：手写实现只支持 alphanumeric 模式，URL 中的 `? & =` 及中文 `indexOf` 返回 -1，生成乱码二维码扫不出
- 条形码：手写的 CODE128B 码表只有 100 项，访问索引 104/106 越界崩溃

**修复**：
- 引入业界标准库 **ZXing (com.google.zxing:core:3.5.3)**
- 二维码用 `MultiFormatWriter` + UTF-8 编码，自动选择最佳编码模式
- 条形码用 ZXing 的 `BarcodeFormat.CODE_128`，码表完整
- URL、中文、特殊字符、emoji 全部正确生成

### 2.2 单位换算：货币汇率实时化

**问题**：货币汇率硬编码，长期不更新，导致换算结果失真

**修复**：
- 新增 `CurrencyRateStore.kt`：从 `open.er-api.com` 实时拉取汇率
- 支持本地缓存（24 小时有效期）
- 缓存失效时回退到内置默认汇率兜底，绝不返回空
- 网络请求与解析放在 IO 协程，不阻塞 UI

### 2.3 壁纸画廊：预览与实际一致

**问题**：预览用一种渲染方式，实际设置壁纸用另一种，导致「所见非所得」

**修复**：
- 重构 `renderWallpaperToBitmap`，使用 Compose `Canvas(ImageBitmap)` 统一渲染
- 预览与实际设置走同一套绘制代码
- 真正实现所见即所得

### 2.4 待办清单：本地持久化

**问题**：待办数据存在 `remember` 状态中，退出应用即丢失

**修复**：
- 新增 `TodoStore.kt`：基于 SharedPreferences + JSON 的本地持久化
- 增删改自动同步到磁盘
- 启动时自动加载历史数据

### 2.5 日历日程：事件提醒

**问题**：日历只能看事件，不能到点提醒

**修复**：
- `CalendarEvent` 数据类新增 `reminderTime` 字段
- `ReminderScheduler.kt`：使用 AlarmManager 设置精确闹钟（Android 12+ 申请 SCHEDULE_EXACT_ALARM，未授予时回退非精确）
- `ReminderReceiver.kt`：接收闹钟广播，创建通知渠道并发送高优先级通知
- UI 提供 5 种预设提醒（准时/5分钟/30分钟/1小时/1天前）+ 自定义时间
- 应用启动时自动 reschedule 所有未到期提醒

### 2.6 颜色选择器：文案对齐

**问题**：「取色」Tab 名与实际功能（色带取色）不符

**修复**：
- Tab 名改为「色带取色」
- 描述文案改为「点击或拖动下方色带选取颜色」

### 2.7 移除声波可视化

**问题**：用户反馈「花架子无用」「猎奇」

**处理**：
- 删除 `VisualizerScreen.kt`
- 移除 `HomeScreen` 中的入口
- 由新的音乐播放器模块替代其位置

## 三、法律与公告中心

### 3.1 动因

为满足应用商店上架与法规合规要求，需提供完整的法律协议。用户要求 4-7 篇，每篇几万字。

### 3.2 实现

新增 3 个文件：

- `LegalDocuments.kt`：5 篇协议正文数据 + LegalItem 元数据
- `LegalCenterScreen.kt`：协议列表页（关于页内入口）
- `LegalDocViewerScreen.kt`：单篇协议阅读页

### 3.3 收录协议（5 篇）

1. **隐私政策**：数据收集/使用/存储/共享/转让/披露/保护/主体权利/Cookie/未成年人/出境/更新机制，依据《个人信息保护法》等制定
2. **用户服务协议**：定义/服务内容/账号/行为规范/知识产权/付费/广告/服务变更/免责/违约/争议解决/协议变更
3. **免责声明**：应用风险/10大功能模块逐一免责/第三方服务/版权/广告外链/不可抗力/责任限制/健康提示
4. **第三方服务与开源组件说明**：9 项第三方服务 + 6 个 SDK + 7 个开源组件清单，含用途/权限/数据收集/协议
5. **儿童信息保护与社区行为公告**：儿童信息收集/处理/监护人权利/安全提示 + 社区行为底线/内容责任/违规处理/投诉举报

### 3.4 阅读器特性

- **6 档字号调节**（11-16sp），适配不同视力
- **阅读进度条**，顶部实时显示
- **返回顶部悬浮按钮**，滚动超过 2 屏后出现
- **章节标题自动识别**：`第X章`/`第X条`/`《》`/`附录` 分别套用强样式（色条+加粗）
- **列表项渲染**：`-` 开头的列表项自动缩进 + 圆点
- LazyColumn 逐段渲染，长文不卡顿

## 五、AndroidManifest 变更

新增权限：
- `android.permission.SCHEDULE_EXACT_ALARM`：日历精确闹钟（Android 12+）
- `android.permission.USE_EXACT_ALARM`：日历精确闹钟（兜底）
- `android.permission.POST_NOTIFICATIONS`：音乐通知栏 + 日历提醒通知（Android 13+）
- `android.permission.FOREGROUND_SERVICE`：音乐后台播放
- `android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK`：Media3 媒体播放前台服务

新增组件注册：
- `ReminderReceiver`：日历提醒闹钟接收器
- `MusicService`：Media3 媒体播放服务

## 七、已知限制

- 网易云音乐使用非官方网页接口，可能随接口变更而失效，届时需适配
- 部分歌曲因 VIP/版权/地区限制无法播放，属正常现象
- 日历提醒依赖系统闹钟，部分 ROM 省电策略可能延迟提醒
- 法律协议正文为通用模板，正式上架前建议由法务复核
