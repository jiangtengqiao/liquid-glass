# CloudMusic 三端音乐应用 — 完整实施计划

## 1. 摘要
交付一套可真实运行的音乐应用，覆盖 **Android / HarmonyOS / Windows** 三端，功能完全对齐，本次先完成「音乐部分」，并内置全套法律合规文档（9 份，三端「设置-关于与法律」页面全文展示，与 `docs/legal/` 同源）。

数据链路：三端客户端 → 自托管 NeteaseCloudMusicApi（开源社区项目 Binaryify/NeteaseCloudMusicApi，MIT）→ 网易云音乐服务。API 地址在三端设置页均可配置（模拟器 `10.0.2.2:3000` / 真机局域网 IP / Windows `localhost:3000`）。

## 2. 技术选型
| 端 | 技术栈 | 播放引擎 | 系统媒体集成 | 网络层 | 本地存储 |
|---|---|---|---|---|---|
| Android | Kotlin 2.0 + Jetpack Compose (Material3) | Media3 ExoPlayer 1.4 | MediaSessionService 锁屏媒体通知（封面+进度+控制）、状态栏常驻 | Retrofit2 + OkHttp + Gson | DataStore Preferences；SharedPreferences 持久化 Cookie |
| HarmonyOS | ArkTS + ArkUI，API 12+，Stage 模型 | @kit.MediaKit media.AVPlayer | @kit.AVSessionKit mediaSession（系统媒体中心/锁屏元数据+控制） | @kit.NetworkKit http | @kit.ArkData preferences |
| Windows | C# / .NET 8 WPF + CommunityToolkit.Mvvm | LibVLCSharp 3.8 + VideoLAN.LibVLC.Windows | SMTC 尽力集成（GlobalSession，反射兜底）+ 窗口标题 | HttpClient + CookieContainer | JSON 配置文件 |
| API 服务 | Node.js（NeteaseCloudMusicApi 自托管） | — | — | — | — |

## 4. 功能清单（三端一致，本次交付）
1. **登录**：扫码登录（`/login/qr/key`+`create(qrimg)` 展示二维码，轮询 `check` 802→803 取 Cookie）、手机验证码登录（`captcha/sent` + `login/cellphone`）、登录态持久化、退出登录
2. **发现**：每日推荐（需登录）、推荐歌单、新歌速递、排行榜（toplist）、歌单广场（catlist 分类 + top/playlist 热歌单）
3. **搜索**：热搜词、输入建议、单曲/歌单/歌手/专辑/MV 多类型结果
4. **播放**：真实在线播放；音质档位 standard/higher/exhigh/lossless 可切换（VIP 受限曲目自动降档重试）；播放队列；顺序/单曲循环/随机；上一曲/下一曲；拖动进度；后台与锁屏持续播放
5. **歌词**：LRC 实时解析滚动高亮；原词/翻译/罗马音切换；DIY 歌词导入编辑；时间偏移 ±0.5s 步进与复位；字号调节；点击歌词行跳转
6. **歌曲详情**：歌曲页 → 歌手页（热歌+专辑）/ 专辑页（全曲播放）/ MV 播放页
7. **歌单**：详情+完整曲目（`playlist/track/all`）、收藏/取消收藏（`playlist/subscribe`）、我的歌单、我喜欢（`likelist`+`like`）
8. **用户中心**：资料、统计、退出
9. **设置**：API 地址、主题色色板（网易红/绯红/薄荷绿/海盐蓝/暗夜紫/琥珀橙）、深色模式、歌词默认字号/偏移/模式、DIY 歌词管理、关于与法律（9 份文档全文）
10. **系统集成**：Android 锁屏媒体通知+状态栏常驻；HarmonyOS 系统媒体中心；Windows 媒体信息尽力集成
